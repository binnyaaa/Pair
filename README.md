# 페어틀 메이커

커플 페어틀을 채워서 PNG 이미지로 저장할 수 있는 웹 편집기예요.

## 사용법

1. 오른쪽 편집 패널에서 항목을 열고 내용을 입력해요.
   - 기본 정보, 캐릭터 A·B, 관계, 관계 지수·변화, 페어 테마곡, 색상
   - 미리보기에서 바꾸고 싶은 곳을 누르면 그 입력칸으로 이동해요.
2. 캐릭터 이름을 넣으면 A / B 표기가 이름으로 바뀌어요.
3. **사진 올리기**로 일러스트와 앨범 커버를 넣어요.
   - 미리보기에서 사진을 끌어서 위치를 옮겨요.
   - 마우스 휠이나 두 손가락으로 확대·축소해요.
4. 다 채웠으면 **PNG로 저장**을 눌러요. (1920 × 1080)
   - 입력하지 않은 칸은 저장한 이미지에 나오지 않아요.
5. 작업 내용은 브라우저에 자동으로 저장돼요.
   - 다른 기기에서 이어 하려면 **작업 파일 저장**으로 받은 파일을 **작업 파일 불러오기**로 열어요.
   - **모두 비우기**를 두 번 누르면 처음부터 다시 쓸 수 있어요.
